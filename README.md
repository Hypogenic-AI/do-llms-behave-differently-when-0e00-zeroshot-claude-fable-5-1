# Do LLMs behave differently when the prompt reads as LLM-written?

**Short answer from this study: not because of authorship.** With content, length, formality and paraphrasing
controlled, six chat models do not measurably change refusal or sycophancy when a prompt reads as LLM-written
rather than as carefully human-written. They do respond to how *formal* and, more strongly, how *elaborate* a
prompt is. Paper: [`paper_draft/main.pdf`](paper_draft/main.pdf).

## Question

Safety evaluations and multi-agent systems feed models prompts written by other models. If "reads LLM-written"
shifts behaviour, evaluation results may not transfer to human users. We ask (a) whether safety-relevant
behaviour changes with the style of the user prompt when content is fixed, and (b) whether any change is driven
by an internal "LLM-written" representation or by surface features (length, formality, having been paraphrased).

## What was done

- **Stimuli.** 1,384 items after filtering: JailbreakBench harmful/benign, XSTest safe/unsafe, TruthfulQA
  (plain, and with a user-suggested misconception), WildChat first turns, and natively LLM-written political
  sycophancy items from Anthropic's model-written evals. Each human-origin item was rewritten by GPT-4.1 into
  casual-human, formal-human, LLM, LLM-long (orchestrator-style elaboration) and casual-long (a casual restyling
  of the LLM-long text) variants. A judge checked every rewrite for content fidelity. A second rewriter
  (Gemini 2.5 Flash) was used as a robustness check.
- **Explicit labels.** "This message was generated by an AI" vs "typed by a human" (and test vs deploy) prepended
  to the unchanged original.
- **Models.** Qwen2.5-7B-Instruct, Llama-3.1-8B-Instruct, Gemma-2-9B-it (behaviour + activations);
  GPT-4.1-mini, Llama-3.3-70B, Claude Haiku 4.5 (behaviour only).
- **Behaviours.** Refusal (harmful and borderline-benign requests), sycophancy to a suggested misconception
  (TruthfulQA), opinion sycophancy (model-written evals), accuracy. Judged by GPT-4.1-mini, blind to the style
  condition (refusal judge agreement with a second judge: kappa 0.94; sycophancy: kappa 0.50).
- **Mechanism.** Difference-of-means directions for LLM-vs-casual style, formality, LLM-vs-formal residual,
  length, stated authorship, evaluation awareness and refusal; probes; and steering on the original prompts with
  the text held fixed, in units of the natural LLM-minus-casual gap, against norm-matched random directions.

## Main findings

| Finding | Evidence |
|---|---|
| Authorship with formality matched has no detectable effect | LLM − formal-human: mean abs. difference 1.7 points over 30 model × outcome cells, largest 5.6, one nominally significant cell; median CI half-width 3.1 points |
| Elaboration matters most | Long vs short versions of the same request: harmful refusal −10 to −15 points in Qwen, Llama-3.1, Gemma and GPT-4.1-mini (not in Llama-3.3-70B or Haiku 4.5) |
| Formality has small, model-specific effects | Casual harmful requests are refused slightly more in all six models (formal − casual −2.5 to −13.7); Claude Haiku 4.5 declines model-written political items 18 points more often in formal than in casual wording |
| Paraphrasing alone lowers refusal | LLM paraphrase − original: −3 to −11 points on harmful requests, so a naive human-vs-LLM-rewrite comparison overstates an "authorship" effect |
| The internal "LLM-written" direction is mostly formality | AUC ≈ 1.0 for LLM vs casual, transfers across datasets; ≈ 0.5 for LLM vs formal-human; cosine 0.67–0.89 with the formality direction. A dedicated probe still separates LLM from formal-human at ≈ 0.92 |
| Steering along it at natural magnitude does nothing detectable | Changes within the range of random directions; the refusal direction at the same norm moves refusal by up to 84 points |
| Stated authorship is a different variable | "AI-written" label: borderline refusal +0 to +5 points, TruthfulQA sycophancy lower in 5 of 6 models; its direction is nearly orthogonal to style (cos 0.14–0.19) and controls the verbal authorship judgement (Qwen: P(AI) 0.01 → 0.99) |
| Small models cannot verbalise authorship from style | Llama-3.1-8B and Gemma-2-9B call the casual version "AI-generated" 77% and 87% of the time; GPT-4.1-mini and Haiku 4.5 are right about 80% vs casual but at chance vs formal-human or the human original |

Caveats (see the Limitations section of the paper): the "human-style" variants are LLM imitations; effects
below about five points per model are not excluded; the harmful subset is filtered by what the rewriter would
restyle faithfully; steering was done at one pre-chosen layer; many contrasts are reported without
multiple-comparison correction.

## Layout

```
src/                 code (see below)
results/             raw model responses with judge labels (*.jsonl), summaries (*.json), stimuli/
paper_draft/         main.tex, sections/, tables/ (generated), figs/ (generated), main.pdf
logs/                run logs
data/, models/       caches, activations, weights (git-ignored)
```

Key result files: `results/behave_summary_gpt41.json` (all behavioural contrasts),
`results/behave_summary_gemini.json` (second rewriter), `results/probes_<model>.json` (probe AUCs, cosines),
`results/steer_summary.json` (steering), `results/sweep_<model>.json` (layer sweep),
`results/pair2afc_*_summary.json` (authorship forced choice), `results/judge_validation.json`,
`results/syco_second_judge.json`.

## Reproduce

Requires one GPU with about 48 GB, `HF_TOKEN` (gated Llama/Gemma weights) and `OPENROUTER_KEY`.
API cost of the full study was about $43; GPU time about 9 hours on an RTX A6000.

```bash
uv venv .venv && source .venv/bin/activate
uv pip install -r requirements.txt sentencepiece protobuf pytz tqdm statsmodels pymupdf
# (this torch build tried to JIT with triton and needs a C compiler; `uv pip uninstall triton` avoids that)
export HF_HOME=$PWD/models/hf
mkdir -p data && curl -sL -o data/xstest.csv https://raw.githubusercontent.com/paul-rottger/xstest/main/xstest_prompts.csv

python src/build_data.py                                   # base items
python src/rewrite.py openai/gpt-4.1 gpt41                 # style variants + fidelity filter
python src/rewrite.py google/gemini-2.5-flash gemini jbb,xstest,tqa_sug

for m in qwen llama gemma; do
  python src/run_behave.py $m            # behaviour, activations, authorship judgements
  python src/judge.py results/behave_${m}_gpt41.jsonl
  python src/directions.py $m            # directions, probes, cosines
  python src/run_sweep.py $m             # layer sweep + forced-choice with reasoning
  python src/run_behave.py $m gemini && python src/judge.py results/behave_${m}_gemini.jsonl
done
python src/run_steer.py qwen 14; python src/run_steer.py llama 16; python src/run_steer.py gemma 21
python src/judge.py results/steer_qwen.jsonl results/steer_llama.jsonl results/steer_gemma.jsonl

(cd src && python run_api.py openai/gpt-4.1-mini gpt41mini && python run_api.py meta-llama/llama-3.3-70b-instruct llama70b \
        && python run_api.py anthropic/claude-haiku-4.5 haiku45)
python src/judge.py results/behave_gpt41mini_gpt41.jsonl results/behave_llama70b_gpt41.jsonl results/behave_haiku45_gpt41.jsonl

python src/analyze_behave.py gpt41 qwen llama gemma gpt41mini llama70b haiku45
python src/analyze_behave.py gemini qwen llama gemma
python src/analyze_steer.py qwen llama gemma
(cd src && python judge_validate.py && python judge_second.py)
python src/make_tables.py && python src/make_figs.py
(cd paper_draft && latexmk -pdf main.tex)
```

Run `judge.py` on a results file only after the generating run has finished (it rewrites the file in place).
API calls are cached in `data/api_cache.jsonl`, so rewrites and judgements are not repeated on rerun; rewrites
were sampled at temperature 0.7, so a run from an empty cache will produce different variant texts. The exact
variants used here are in `results/stimuli/`.

## Notes on the run

- Gemma's first behaviour run crashed with an out-of-memory error (full-vocabulary logits) after the
  authorship-judgement stage; the code was fixed to compute last-position logits only and the run was repeated.
  See `logs/behave_run1.log`.
- The single-letter forced-choice authorship question (`results/pair2afc_<model>_gpt41.json`) is dominated by
  position bias and is not used in the paper; the version with brief reasoning is.
